进阶操作

1. rebase（变基）

将当前分支的提交“平铺”到目标分支之后，使提交历史更干净。

注意：

  • rebase 会修改历史，用于自己分支更清晰

  • 合并冲突后需 git rebase --continue

2. reflog（查看历史 HEAD）

当误删分支、reset 错误时，可通过 reflog 找回提交。

3. submodule（子模块）

适用于将另一个 Git 仓库作为当前项目的一部分。

4. Git Hooks（钩子脚本）

自动在某些 Git 操作前后执行脚本，例如提交前代码检查。

路径：.git/hooks/，常用如：

  • pre-commit：提交前运行 lint 工具

  • post-merge：合并后自动构建
